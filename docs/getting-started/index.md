# Getting started

Three short guides to get the desktop running and to understand the Nix
tooling that ships with it.

- [Quick start](quickstart.md) — pull the image from GHCR and run it with
  Docker or Docker Compose.
- [Nix workflow](nix-workflow.md) — the `nix run .#*` convenience targets
  for building, running, and demoing the various security postures.
- [Building from source](building.md) — build the image locally with Nix or
  the `make` wrappers, and understand the SBOM and CVE artefacts each build
  produces.
